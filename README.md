# 符冬便利店 · 网页工作台

一个纯静态网页的个人任务看板，适合部署到 GitHub Pages 或其他静态网站托管平台。

## 功能

- 待开始 / 进行中 / 已完成任务看板
- 创建、编辑、删除任务，设置分类、优先级、截止日期和描述
- 搜索、筛选、拖拽切换任务状态
- 灵感便签与每日目标
- 自动保存到当前浏览器的本地存储
- JSON 备份导出与导入
- 自适应桌面与窄屏布局
- 页面样式与插画资源内嵌，无需安装依赖、构建工具或后端服务

## 本地预览

直接用现代浏览器打开 `index.html` 即可。也可以在项目目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 部署到 GitHub Pages

1. 将项目文件上传到 GitHub 仓库的根目录，确认 `index.html` 在根目录。
2. 如果使用 GitHub Free，仓库需要设为 **Public** 才能使用 GitHub Pages；公开前请确认仓库里没有不想公开的内容。
3. 进入仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/(root)`，保存。
6. 等待部署完成，Pages 页面会显示网站地址，通常形如 `https://<用户名>.github.io/<仓库名>/`。

## 数据与隐私说明

这是纯前端网页，不包含账号系统和远程数据库。任务、分类、便签、每日目标保存在当前浏览器的 `localStorage` 中，不会自动上传到 GitHub 或传给网站服务器。

- 同一个浏览器、同一个网站地址下的数据通常可以继续使用。
- 换浏览器、换电脑或清除网站数据后，不会自动同步；请先从页面导出 JSON 备份，并在另一台设备导入。
- GitHub Pages 上的网页本身可公开访问。不要在初始任务或仓库中放置秘密、密码或敏感信息。

## 技术说明

- 单文件 HTML + 内嵌 CSS/JavaScript
- 无外部 CDN、无包管理器、无需编译
- `.nojekyll` 用于告诉 GitHub Pages 不运行 Jekyll 处理
