# 符冬便利店 · 本地项目工作台 V5

一个纯静态网页，不需要后端或网络账号。项目、提醒事项、用户设置和本地自动快照都保存在当前浏览器的 IndexedDB 中。

## 当前功能

- **工作台总览**：项目统计、月历、当天安排、近期提醒和项目摘要。
- **项目分类**：管理项目，并在项目详情内创建与项目关联的提醒事项。
- **提醒事项总览**：查看提醒、按项目筛选，并跳转回所属项目。
- **多本地用户**：每个用户独立数据和 4 位数字 PIN。
- **锁屏**：重新打开网页和连续闲置 5 分钟后需要解锁；支持手动锁屏。切换用户也必须输入对应 PIN。
- **头像上传**：本地缩放压缩后保存在浏览器，不上传图片。
- **页面配色**：薄荷、海盐蓝、樱花粉、薰衣草、夜间深色五种配色。
- **加密备份**：使用 PIN 派生密钥和 AES-GCM 加密 JSON 备份；在另一个浏览器中输入原 PIN 即可解密并恢复为一个新本地账户。
- **自动备份**：自动快照以加密形式保存于本机，可单独下载。
- **用户删除**：二次确认后删除所选用户及其项目、提醒、设置和本地快照。
- 页面底部提供 BUG 反馈提示。

## 首次使用

1. 创建本地用户，上传头像（可选），设置并确认 4 位 PIN。
2. 创建项目，或直接创建第一份提醒事项。
3. 后续访问相同的网站地址时，页面会锁定并要求 PIN，解锁后恢复数据。

## PIN 与备份安全说明

- PIN 校验信息以 PBKDF2 派生的哈希和随机盐保存，不保存 PIN 明文。
- 导出的备份使用 PBKDF2-SHA-256 派生 AES-GCM-256 加密密钥；备份文件包含随机盐、随机 IV 和密文，不含明文项目/提醒数据。
- 更换浏览器导入加密备份时输入导出时的 PIN；正确解密后会在新浏览器创建一个新的本地用户，不会覆盖现有用户。
- **4 位 PIN 只有 10,000 种组合，强度有限**。这套机制适合日常本地访问控制，但无法防御能直接操作浏览器开发工具、读取本地数据库或对备份文件进行离线猜测的人。请不要存放高敏感数据；同时请将备份文件保存到安全位置。

## 数据边界

数据只属于当前浏览器配置文件与当前网站来源，不会自动上传或跨设备同步。使用无痕窗口、更换浏览器/设备或清除网站数据，都需要从加密备份恢复。定期下载备份文件；忘记 PIN 时没有服务器找回流程。

自动快照在浏览器打开或重新切回页面时检查是否到期。关闭网页期间，浏览器不会在后台持续运行定时器。

## 兼容

旧版本的模板和记录存储不会在数据库升级时删除，但不再作为主导航功能展示。旧版未加密备份可在已解锁账户中导入；如要在另一浏览器恢复，建议先在旧版本导入原数据，然后从 V5 导出新的加密备份。

## 本地预览与部署

- 直接打开 `index.html` 可以预览界面；加密功能要求支持 Web Crypto 的现代浏览器。
- GitHub Pages 使用仓库根目录 `index.html`，分支 `main`、目录 `/(root)`；不需要安装依赖或构建步骤。
