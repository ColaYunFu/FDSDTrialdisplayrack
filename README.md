# 符冬便利店 · 网页工作台

一个纯静态网页的个人任务看板，可部署到 GitHub Pages 或其他静态网站托管平台。

## 功能

- 待开始 / 进行中 / 已完成任务看板
- 创建、编辑、删除任务，设置分类、优先级、截止日期和描述
- 搜索、筛选、拖拽切换任务状态
- 灵感便签与每日目标
- 自动保存到当前浏览器的本地存储
- JSON 备份导出与导入
- 自适应桌面与窄屏布局
- 无需安装依赖、构建工具或后端服务

## 本地预览

直接用现代浏览器打开根目录的 `index.html` 即可。

## 数据说明

任务默认保存在当前浏览器的本地存储中，不会自动在不同设备之间同步。建议定期导出 JSON 备份。
