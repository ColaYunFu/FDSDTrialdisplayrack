# 符冬便利店 · 本地项目工作台 V4

一个纯静态网页，不需要后端或网络账号。项目、提醒事项和备份都保存在当前浏览器的 IndexedDB 中。

## 导航结构

- **工作台总览**：项目与提醒统计、月份日历、选中日期的安排、即将到期事项、项目摘要。
- **项目分类**：创建/编辑/删除项目，在项目详情里创建关联提醒。
- **提醒事项总览**：查看全部、待处理和已完成的提醒；按项目筛选；从每条提醒跳转到关联项目。
- **数据备份**：导出/导入 JSON、本地快照、可选自动备份周期。

## 空白初始化

第一次使用先创建本地用户。新用户没有预置项目或提醒。创建后可先建项目，也可以直接建立第一份提醒事项。

## 本地数据与隐私

用户、项目、提醒事项和设置存放在当前网站来源下的 IndexedDB 中。localStorage 只用于记住上次选择的本地用户。数据不会上传到服务器，也不会跨设备自动同步。

若更换浏览器/设备、使用无痕窗口或清除网站数据，必须从 JSON 备份恢复。自动快照只存在本机浏览器中，建议定期下载到电脑。

## 兼容说明

旧版中的模板与记录存储不会在数据库升级时自动删除。V4 不再把「我的模板」和「我的记录」作为导航模块；旧数据会保留在本地兼容存储中。

## 部署

请将 index.html 放在 GitHub Pages 仓库根目录，并选择 main + /(root) 发布。无需安装依赖或执行构建。
